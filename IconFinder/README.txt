Icon Finder 0.2.0

Install
1. Quit the game completely (a /reload does not pick up a new addon).
2. Unzip IconFinder.zip into your AddOns folder, so you end up with
   World of Warcraft\_forever_\Interface\AddOns\IconFinder\IconFinder.toc
   (use the folder for your game version if it's named differently).
3. Start the game and make sure Icon Finder is ticked in the AddOns list.

Use
- Open your macros (/macro), pick a macro and click Change (or make a new one).
  A "Search icons" panel appears to the right of the icon list.
- Type a spell or item name, like "frost" or "hearthstone". Icons whose names
  start with what you typed come first. Hover an icon to see its name and ID,
  click it to use it, then press Okay as usual.
- You can also type a number: it's tried as an icon ID, a spell ID and an item ID
  (handy if you found an icon on Wowhead).
- The first time you open the picker after logging in, it reads all spell
  names in the background for a few seconds. Results fill in as it goes.
- The "Pinned and recent" row at the top shows icons you pinned, then the icons
  you saved most recently (pressing Okay counts, however you picked the icon).
- Right-click any icon in the panel to pin it, and right-click it again to
  unpin. You can pin 8. Pinned icons have a small gold mark.
- It also works on the equipment set icon picker.

Good to know
- The game doesn't give addons the file names of icons, so searching for words
  like "sword" only finds spells and items that have that word in their name.
- The red question mark icon with #showtooltip at the top of a macro shows the
  icon of whatever the macro casts, so you may not need to pick one at all.
