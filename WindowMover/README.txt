Window Mover 0.2.0

Install
1. Quit the game completely (a /reload does not pick up a new addon).
2. Unzip WindowMover.zip into your AddOns folder, so you end up with
   World of Warcraft\_forever_\Interface\AddOns\WindowMover\WindowMover.toc
   (use the folder for your game version if it's named differently).
3. Start the game and make sure Window Mover is ticked in the AddOns list.

Use
- Open your bags, character pane, spellbook and talents, map and quest log,
  collections or a profession window. A small "Move" button sits at the top
  right, next to the close button (on the map it sits left of the maximize button).
- The map is only moved while it's the small version. A maximized map stays put.
- Hold the Move button and drag to move the window. It remembers the spot, also after logging out.
- Right-click the Move button to put the window back where it was.
- /wmover reset puts every window back. /wmover reset followed by bags, character,
  spellbook, quests, collections or professions resets just that one.
- /wmover lock hides the Move buttons (and /wmover lock again brings them back).
- /wmover status lists the windows that have a Move button.
